## 0.1.1

- MKV, AVI, WMV, FLV, MPG, M2TS and other video files open in the video player instead of as text.
- VS Code themes such as Tokyo Night and Nord install again from the theme gallery.

## 0.1.0

The first release.

- Browse, search, view and copy files on all your Windows and Linux computers from one browser window.
- Direct copies between computers that pick up where they stopped after a network drop or restart.
- Instant search across every drive, kept up to date as files change.
- Undo (Ctrl+Z) for copies, moves, renames, deletes, archives and scripts.
- Video playback for formats browsers cannot play (converted on the fly), e-books, Markdown, HTML, PDF, code.
- Zip, 7z, tar and rar open like folders; files can be copied into a zip.
- Copy queues per disk, disk usage charts, duplicate finder, folder sync, multi-rename, checksums, conversions.
- Personalities: the keys and look of Total Commander, Midnight Commander, Far, yazi, ranger and others.
- Guest passwords that show only the folders you share.
- Installer scripts for Windows and Linux: install, update, roll back and uninstall.
